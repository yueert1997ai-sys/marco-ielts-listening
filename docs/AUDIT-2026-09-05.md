3. **错词永久身份被赦免清除**：`pardonErrorWord` 与 sanitizer 把 isErrorWord 设 false。历史计数没删，但身份和活跃状态混在一起。
4. **旧错误档案迁移不完整**：给普通词旧 progress 写入 lapses=3 后刷新，errorWords 中仍不存在它；静态真实错词中非个人同步来源也未完整播种。

6. **错词口径不一致**：“全部错词”排除了已赦免；普通词库“我的错词”按静态 isRealError，档案按 errorWords；复习池从 progress 去模式后去重，但未去除 :vocab 后缀。

### P2 / 后续优化

- 错词档案缺搜索、A/B/活跃明确分组、首次错误和最近训练展示；一次渲染约 200 张卡。
- S 级规则含永久 wrongCount≥2 或 causedIeltsError，已稳定掌握的历史高错词无法降级。未来到期词仍会补入每日额度。

## 学习效率与最值得做的五件事

1. 保护导入/保存：先完整验证候选数据，失败不改内存或磁盘；保存失败明确提示并允许导出。
2. 永久错词档案：赦免只改活跃状态，迁移旧错误，不删来源和重点。
3. 固定当日任务：刷新/返回不补题；进度仅统计同一批 baseKeys；跨天重新排期。
4. 统一重点、筛选、数量：同一份档案衍生全部/活跃/赦免/S-A-B，复用分页降低长列表负担。
5. 同日认识不反复升阶段，到期再推进；难词提权但熟词允许降低频率。

